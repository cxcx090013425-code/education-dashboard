# 教育行业看板

## 定位
Terra 和 Tellus 的教育行业信息雷达。每周汇总一次，长期积累形成自己的信息库。

## 目的
1. 了解 AI + 教育领域国内外同行在做什么
2. 发现可借鉴的开源项目、工具、教学方法
3. 追踪教育科技市场的商业动态（融资、产品、用户反馈）
4. 为自己的教育项目开发、策划和商业落地提供信息支撑

## 看板结构（每周一期）

### 一、开源项目追踪
- GitHub 教育类高赞项目（新增/趋势）
- 与我们相关的工具（词汇生成、教案模板、闪卡、阅读辅助）
- 值得关注的技术（间隔重复、文档生成、AI 教学）

### 二、国内教育科技动态
- 抖音/小红书/视频号上的教育类热门内容
- 国内教育 APP 新产品/新功能
- 政策动向（如教育信息化、AI 进课堂等）

### 三、国外教育科技动态
- 海外教育科技产品/平台更新
- 教育类 SaaS 产品动态
- 研究报告和趋势分析

### 四、商业与市场数据
- 教育科技融资信息
- 收费模式和定价参考
- 用户群体和市场反馈
- 竞品分析（如有）

### 五、对我们的启发
- 可以借鉴的点子
- 可以合作/集成的工具
- 需要警惕的风险

## Tellus 工作流程（后台执行）

### 信息收集阶段

1. **搜索**：按信息来源平台列表，逐个平台搜索关键词
2. **筛选**：从搜索结果中筛选与教育看板相关的内容
3. **内容真实性判断**（必须在筛选阶段完成）：

   判断每条信息是人写的还是 AI 生成的，方法：

   | 判断维度 | 人工内容特征 | AI 生成特征 |
   |---------|------------|-----------|
   | **语言风格** | 有个人口癖、情绪波动、不完美 | 过于流畅、工整、无个性 |
   | **细节深度** | 有具体场景、人名、时间、地点 | 泛泛而谈、缺少具体细节 |
   | **观点立场** | 有明确立场，可能偏激 | 面面俱到、"一方面…另一方面" |
   | **来源出处** | 引用具体报告/采访/数据 | "据报道"不给链接 |
   | **互动痕迹** | 评论区有真实讨论 | 评论少或评论也是套话 |
   | **平台特征** | 知乎/小红书真人号有历史内容 | 营销号集中发同质内容 |

   **筛选原则**：
   - **优先采纳**：人写的、有观点的、有具体细节的
   - **谨慎采纳**：AI 辅助但有人工审核的（如大号用 AI 辅助写作）
   - **不采纳**：纯 AI 生成、无来源、无细节的水文

4. **核实**（必须在发布前完成）：
   - 每条信息的外部链接**必须点开确认**能打开
   - 确认打开后的内容和看板描述一致
   - 确认信息是近期的（标注发布日期）
   - 确认来源可靠（不是营销号、不是虚假新闻）
   - 数字必须标注具体来源
5. **交叉验证**：对重要信息反搜相反观点

### 发布阶段

1. 标注每条信息的来源和核实状态（已核实/未核实）
2. 列出本周搜索关键词和平台覆盖
3. 公开勘误记录（如有）
4. **Tellus 不跳过核实步骤直接发布——这是红线**

### 输出位置

### 六、反圈养机制

防止信息壁垒的核心原则：**信息源、搜索逻辑、反面观点必须透明**。

| 机制 | 怎么做 |
|------|--------|
| **来源标注** | 每条信息标注具体来源（平台+链接），不放无来源的信息 |
| **链接可点开** | 所有链接必须真实有效，404 的链接不能上看板 |
| **核实机制** | 每条信息发布前必须点开链接核实：能打开、内容匹配、时效性OK |
| **可验证性** | 只有附带可点开外部链接的信息才能标"已核实"；没有外部链接的只能标"Tellus 观点"或"Tellus 分析"，不能标"已核实" |
| **搜索透明** | 每期底部列出"本周搜索关键词"和"信息平台覆盖"，让 Terra 一眼看到信息触角在哪 |
| **用户定方向** | Terra 每周可以给关键词/关注点，Tellus 按此搜索；没给则用默认清单，默认清单可随时改 |
| **反向验证** | 对每条重要信息反搜是否有相反观点或争议，看板设"争议/反面"板块 |
| **多平台交叉** | 不只搜 GitHub 和主流媒体：小红书家长反馈、知乎专业讨论、YouTube 海外老师视角 |
| **搜索记录留痕** | 保存每次搜索的关键词和结果数量，可追溯信息获取路径 |
| **勘误机制** | 发现错误立即标注修正记录，不悄悄改掉当没发生过 |

### 七、信息核实清单（每期必做）

1. **内容真实性**：判断每条信息是人写的还是 AI 生成的（见判断维度表）
2. **链接可点开**：每个外部链接用浏览器打开，确认不是 404
3. **内容匹配**：链接打开后的内容和看板描述一致
4. **时效性**：信息是近期的（标注发布日期）
5. **来源可靠**：不是营销号、不是虚假新闻
6. **数据有出处**：数字标注具体来源，不说"据报道"而不给链接
7. **优先人写的内容**：人写的 > AI辅助人审核的 > 纯AI生成的
